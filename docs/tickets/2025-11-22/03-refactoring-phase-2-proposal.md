# Timeline リファクタリング Phase 2 提案

Phase 1（ユーティリティとヘッダーの切り出し）が完了し、ファイルサイズは約13%削減されました。
さらなる保守性向上のため、以下のリファクタリングを提案します。

## 優先度: 高（視覚的な分離）

### 1. タイムライングリッドの切り出し (`TimelineGrid.tsx`)
**現状**: `renderColumn`, `renderEvent`, `renderFloatingLayer` など、時間軸とイベント表示のロジックがメインファイルに残っています。
**提案**: これらを `TimelineGrid` コンポーネントに移動します。
**メリット**:
- メインファイルから「表示ロジック」を分離できる
- グリッドの描画パフォーマンスを最適化しやすくなる

### 2. A/B バケットの切り出し (`TimelineBuckets.tsx`)
**現状**: `renderAbCard` 関数で左側のバケットを描画しています。
**提案**: これを `TimelineBuckets` コンポーネントに移動します。
**メリット**:
- タイムライン（時間軸）とバケット（タスクリスト）の責務が明確になる

## 優先度: 中（ロジックの分離）

### 3. ドラッグ＆ドロップロジックのフック化 (`useTimelineDragAndDrop.ts`)
**現状**: `handleDragStart`, `handleDragMove`, `handleDragEnd` など、約200行の複雑なDNDロジックが存在します。
**提案**: これらをカスタムフック `useTimelineDragAndDrop` に抽出します。
**メリット**:
- 複雑な状態管理ロジックを隠蔽できる
- テストがしやすくなる

### 4. データ取得・モーダルロジックのフック化
**現状**: カード詳細モーダルの読み込みや保存処理 (`loadCard`, `handleCardModalSave` など) が混在しています。
**提案**: `useCardModal` フックなどに抽出します。

## 推奨する進め方

まずは **1. タイムライングリッド** と **2. A/B バケット** の切り出しをお勧めします。
これらは視覚的なコンポーネントなので、切り出しによる影響が分かりやすく、かつファイルサイズ削減効果も大きいです（さらに300〜400行程度の削減が見込めます）。
