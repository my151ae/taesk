# 03 - Filters & Search

## 目的
旧 Kanban で提供していたフィルター／検索体験（タグ・テキスト・優先度など）を Timeline UI にも適用し、カードの絞り込みが行えるようにする。

## 作業項目
- [ ] `useBoardFilters` などのフィルター関連ロジックをフック化し、Timeline でも再利用。
- [ ] タイムラインイベントと A/B リストそれぞれにフィルターを適用。
- [ ] UI（検索バー、フィルタードロップダウン等）を Timeline ヘッダー付近に配置。
- [ ] フィルター状態を URL / ローカルストレージに保存する場合は Kanban と仕様を合わせる。

## 完了条件
- Timeline 上で検索・フィルターを行うと表示がリアルタイムに更新される。
- Kanban と同等のフィルター機能が提供され、UX が一貫している。
